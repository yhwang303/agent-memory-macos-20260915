为 AI 编程助手提供跨会话持久化记忆能力的插件系统

// the problem
解决什么问题

AI 编程助手的上下文窗口是有限且易逝的。每次新开窗口、切换项目、重启 IDE，之前所有的对话上下文全部丢失。开发者不得不反复向 AI 解释"我们项目是干什么的""上次改了哪里""那个 Bug 是怎么修的"。据社区反馈，这个问题导致的重复沟通成本高达总编码时间的 20-30%。

Before — 没有记忆

每次开新窗口，AI 对项目一无所知。反复解释背景、改动历史、踩过的坑。用 10 分钟聊天，3 分钟在给 AI 补课。

After — 有了 Agent-Memory

AI "记住"了之前所有会话的关键操作和知识。新会话自动注入相关历史记忆，直接开口就是"上次你修了 X，现在继续 Y"。

// hooks
11 种 Agent 生命周期 Hook

覆盖 AI 编程助手的完整工作流程 —— 从用户输入、工具调用到 Agent 响应，不遗漏任何关键操作。

Hook类型作用
sessionStart生命周期创建会话记录
beforeSubmitPrompt控制型初始化 + 注入历史上下文到 Prompt
beforeShellExecution控制型Shell 命令隐私过滤（自动脱敏 API Key / 密码）
beforeMCPExecution控制型MCP 工具调用隐私检查
afterShellExecution监控型记录 Shell 命令执行结果
afterMCPExecution监控型记录 MCP 工具调用结果
afterFileEdit监控型记录文件编辑操作
afterSearchReplaceFileEdit监控型记录搜索替换操作
afterAgentResponse监控型捕获 Agent 完整回复
afterAgentThought监控型捕获 Agent 思考推理过程
stop生命周期会话结束 → 触发 Summary 总结生成
// core features
核心功能

从自动记录到智能检索，完整覆盖记忆的采集 → 存储 → 检索 → 注入全生命周期。

自动记录 · 零配置

11 种 Hook 全自动拦截 Shell 命令、文件编辑、MCP 调用、Agent 响应等全部操作类型。开发者无需任何手动操作，正常编码即可。

AUTO

AI 智能压缩 · 结构化 Observation

调用 LLM 将原始操作提取为含 type / title / meta_intent / facts / narrative 的结构化记忆。9 种分类类型（discovery、bugfix、feature、refactor 等），全中文输出。

AI DRIVEN

会话总结 · 端到端生成

会话结束时聚合所有 Observation，自动生成含"做了什么 / 学到什么 / 关键发现 / 下一步建议"的会话 Summary。支持图片语义保留——截图中的信息不会在总结中丢失。

END-TO-END

上下文注入 · 无缝衔接

新会话自动查询最近 5 条 Summary + 10 条 Observation，格式化为 <memory_context> XML 注入 Prompt。4000 Token 上限 + 渐进式裁剪策略，确保不超限。

CORE

RAG 混合搜索

FTS5 全文搜索 + Chroma 向量语义搜索 + RRF 融合排序。支持中文语义理解，hybrid 模式自动降级——Chroma 不可用时无缝回退到 SQLite。

MILESTONE 2

MCP 主动搜索 · 9 个工具

AI 可通过 MCP 协议主动查询：search / search_like / timeline / get_observations / get_summaries / get_stats / list_projects / list_sessions / get_context。推荐 3 层渐进式查询，节省 10x Token。

9 TOOLS

图片语义保留

用户发送截图后，自动检测 [Image] 标记 + 词汇信号（图片/截图/diagram），将 assistant 对图片内容的描述写入 Summary 的 media_context 字段，确保视觉内容不丢失。

MILESTONE 1

远程同步 + 个人服务端

本地记忆可同步到远程服务器。SyncQueue 持久化队列 + 指数退避重试 + 优先级调度（realtime/backfill）。支持 cmem:// 邀请链接一键连接，多设备记忆聚合查看。

MULTI-DEVICE

OpenClaw 网关插件

支持 Telegram / Discord / Slack 聊天网关场景，SSE 实时推送 + 指数退避重连。Setup Wizard 一键安装，自动写入 openclaw.plugin.json + 合并配置。

// ux polish
用户体验优化 · 降低使用摩擦

我们在每个可能产生摩擦的环节都做了优化设计。目标是让用户几乎感知不到记忆系统的存在，但又能时刻受益。

一键安装 · 开箱即用

install.bat / install.sh 一键完成全部流程（检查环境 → 安装依赖 → 编译 → 配置向导）。内置默认 API Key，安装后无需任何额外配置即可使用。桌面端也提供 NSIS 安装包 / macOS DMG 一键安装。

系统托盘守护

Electron 桌面端常驻系统托盘，4 种状态色像素机器人图标（绿/橙/红/灰）直观显示服务状态。Worker 崩溃自动重启（最多 3 次），支持开机自启动。

首次引导 · Setup Wizard

首次启动自动弹出 IDE 关联向导。自动扫描系统中已安装的所有 IDE，一键勾选完成关联，零命令行操作。支持 Cursor / CodeBuddy / Claude Code / OpenClaw 等全平台。

Hooks 自动守护

60 秒轮询检测 hooks.json 完整性。外部程序（如 IDE 更新、Cursor 自动升级）修改或覆盖 hooks 配置后，系统自动恢复注册。新安装 IDE 也会被自动检测并关联。

Hook 失败绝不阻塞

记忆系统出错绝不影响正常编码。架构上采用"HTTP 立即返回 200 + 异步后台处理"模式，10 秒超时硬限制。即使 Worker 完全不可用，AI 编程助手也完全不受影响。

Windows 深度兼容

PowerShell 管道 ExpressionsMustBeFirstInPipeline 问题、空格路径、UTF-8 BOM、GBK 乱码、非管理员权限 EPERM……每一个 Windows 编码/路径/权限陷阱都有专项修复和回归测试。

ShadowFolk 深空主题

全部窗口（Viewer / QuickPanel / Settings / Setup Wizard / Server）统一采用 #0a1014 暗色底 + #00d4aa 青绿强调的 HUD 风格。像素字体标题 + 扫描线 + 发光边框，视觉一致且辨识度高。

自动数据库迁移

版本升级时自动检测缺失列（EXPECTED_COLUMNS 字典驱动），执行 ALTER TABLE ADD COLUMN 补全。有列变更时自动重建 FTS 索引 + 回填数据。用户完全无感。

cmem:// 协议 + 邀请链接

注册自定义 URL 协议 cmem://，支持邀请链接一键连接远程服务器。点击链接自动唤起桌面端、解析连接参数、填入配置。团队共享记忆服务器零门槛。

内置 Node.js 运行时

桌面端打包时内置 node.exe（Windows）/ node（macOS）。Hooks 执行使用内置 Node 而非系统 Node，彻底消除"用户没装 Node"导致的静默失败。

敏感信息自动过滤

所有 Prompt 模板内置敏感信息规则：自动检测 API Key、密码、Token、密钥、证书等模式，强制要求 LLM 用 [REDACTED] 替换。记忆数据库中不会存储任何明文密码。

全局快捷键搜索

Ctrl+Shift+M（macOS 下 Cmd+Shift+M）唤起 Spotlight 风格透明搜索面板。不打断当前工作流，随时快速检索历史记忆。
