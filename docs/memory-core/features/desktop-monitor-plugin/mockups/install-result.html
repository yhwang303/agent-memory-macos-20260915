识别要点

ShadwMonitor Bridge 在 Plugins 段出现, 用 琥珀色点 区分于其他青绿色插件 — 这是 ShadwMonitor 的主题色, 跟 viewer 里的独立 Tab、Stage 1 的设置卡保持一致。

右侧数字 38 today 表示当天已镜像的 L1 moment 数, 点击该行直接跳到上面 Stage 2 的 ShadwMonitor 独立 Tab。 若进程离线则变红色 + 异常计数(如 retry 5), 系统通知中弹出 toast。
本 mockup 不是设计稿, 是预览。 每个 Stage 对应 PRD/design 里说过会发生的真实位置, 颜色来自项目已有的 ShadowFolk Design Tokens。
青绿 = agent-mem 主色 · 琥珀 = ShadwMonitor 插件标识色(贯穿 5 个视图) · 紫 = self-evolve 插件标识色(姊妹插件) · 红 = 异常态。
数字(38 条 L1、421 截图、142 observation 等)为示例值。
