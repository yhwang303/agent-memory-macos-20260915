MODIFIED desktop/src/main.ts
  • 导入并实例化 UpdateChecker

🔗 对接的 API (官网已有, 无需新增)

方法 路径 说明
GET /api/latest/:platform 客户端检查更新用 (win / mac-arm64 / mac-x64)
