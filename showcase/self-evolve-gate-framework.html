Self-Evolve 进化门禁框架

每条 Rule / Skill 从"会话结束"到"写入 IDE 文件"需要通过的完整判断链

1
插件启用检查
本地
▶
config.enabled === true
未启用 → 整个流程不执行
↓
2
重入 + 已处理检查
本地
▶
当前没有正在运行的进化任务
该 session 未在 evolution_log 中出现过（completed / skipped）
已处理 → 跳过（除非 force=true）
↓
3
Observations 非空
本地
▶
observations.length > 0
空会话 → 无内容可学习，跳过
↓
4
增量调度器触发判断 NEW
本地
▶
累积 ≥ 8 条 observation → 按数量触发
用户空闲 ≥ 30 分钟且有积累 → 空闲触发
检测到主题切换（文件前缀 + 类型 + 时间间隔 ≥2 信号）→ 切割触发
两次进化间隔 ≥ 10 分钟（冷却期）
每日上限 ≤ 30 次
触发路径: count_threshold | idle_timeout | topic_switch | session_end
↓
5
AI 判断：工具链维护会话过滤
AI 调用
▶
满足 ≥2 条 → 整个会话跳过：
修改的文件集中在工具链代码（agent-memory/src/, .cursor/hooks/）
出现工具链专有名词（Worker, EvolveEngine, hooks-cli, mcp-server）
会话核心目的是改善 AI 工具链本身
AI 返回 skip_reason 字段 → 有值则跳过
工具链自身维护 → 不提炼（避免循环）
生成阶段 — AI 提炼 Rules & Skills
6
Rule 质量打分
本地打分
▶
维度条件分数
内容长度≥ 80 字符+40
≥ 30 字符（且 < 80）+20
< 8 字符FAIL
行动词包含 必须/应该/不要/禁止/always/never/must/should+20
作用范围有 paths_glob+20
补充长度≥ 40 字符+20
及格线: 60/100
< 60 分 → rejectedRules++，不入库
↓
7
Skill 质量打分（三轮补救）
本地 + AI
▶
维度条件分数
YAML Frontmatter每个字段 (name/description/argument-hint/user-invocable/allowed-tools)每个 +5
内容长度≥ 400 字符+15
≥ 200 字符+10
< 200 字符FAIL
标题数量 (##)每个标题+5 (上限 +20)
协作协议有 "Collaboration Protocol" 段+10
代码块≥ 2 个 ``` 对+10
编号步骤≥ 3 个 "## N."+20
第1轮: 直接打分 第2轮: 自动增强(补frontmatter+协作协议) → 重打分 第3轮: AI重写(buildRefineSkillPrompt) → 重打分 三轮全不及格 → rejectedSkills++
三轮均 < 60 → 拒绝
↓
8
去重 + 防腐败检查
本地
▶
内容与已有 rule/skill 完全相同 → 跳过
文本编码异常（非可打印字符 > 30%）→ rejected
Slug 已存在（skill）→ 跳过或 upsert
后置审查 — Critic 引擎
9
Critic 三项复查
AI 调用 × 3
▶
检查方法判定
冗余检测关键词重叠 > 0.15 → AI 判断是否完全重复overlap ≥ 0.8 → flagged
冲突检测 (仅Rule)同 paths_glob → AI 判断是否矛盾verdict='flagged' → flagged
语义价值AI 判断是否有实际价值verdict='archive' → flagged
autoApplyFixes = false（默认） → 只标记(flagged)不自动拒绝，等人工裁定 → 三项全通过时 Critic 自动 approve
最终决策 — 审核模式
10
审核模式决定写入
配置
▶
模式行为文件写入
auto生成即批准立即写入所有选中的 IDE
quality_gatescore ≥ threshold → 批准
score < threshold → pending		达标的写入；未达标等人审
manual（默认）全部进入待审核队列用户在 viewer 点击"批准"后写入
写入目标（支持多选）: ├─ claudecode → CLAUDE.md + .claude/skills/ ├─ cursor → .cursor/rules/ + .cursor/skills/ ├─ codebuddy → .codebuddy/rules/ + .codebuddy/skills/ └─ windsurf → .windsurf/rules/ + .windsurf/skills/
✓ 批准 + 写入选中 IDE → 完成
关键配置项
reviewMode: auto | manual | quality_gate (默认 manual)
qualityGateThreshold: 0-100 (默认 70)
targetPlatforms: ['claudecode'] (默认，可多选)
criticOnGenerate: true (默认开启 Critic 复查)
incremental.enabled: true (增量进化调度器)
incremental.observationThreshold: 8 (累积触发)
incremental.idleMinutes: 30 (空闲触发)
incremental.cooldownMinutes: 10 (冷却)
incremental.maxDailyRuns: 30 (日上限)
