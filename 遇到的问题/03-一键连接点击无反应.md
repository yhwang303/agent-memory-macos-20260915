# 03 · 设置里"一键连接"按钮点击无反应

## 现象
- 打开桌面端「设置 → 服务器同步」，粘贴邀请链接后点"一键连接"，按钮没动静、状态栏也没变化。
- 控制台没有明显报错，用户以为按钮坏了。

## 根本原因
- 邀请链接解析逻辑只能识别一种格式（标准 `cbmem://invite?...`），用户粘贴的是带前缀/带空白的版本时直接 `return undefined`。
- 表单 submit 没有兜底的"解析失败"提示；解析失败 → 提交链路被静默吞掉 → UI 完全无反馈。

## 解决
1. `desktop/src/config/inviteParser.ts`：扩展解析，去除首尾空白、兼容多种前缀、对常见错误返回明确 `error` 字段。
2. `desktop/src/windows/settings.html`：把按钮改成真正的 `<form>` 提交，新增 invite 状态行（成功/失败/进行中），失败时把 parser 的错误信息回显出来。
3. `desktop/src/windows/SettingsWindow.ts`：把 IPC 调用结果回写到状态行。

## 教训
- 任何"用户输入 → 后台异步动作"的按钮都必须有三态反馈：进行中 / 成功 / 失败。
- 解析器要对脏输入鲁棒，而不是寄希望于"用户会粘贴干净的串"。
